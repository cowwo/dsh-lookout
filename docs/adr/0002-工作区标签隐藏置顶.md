# ADR 0002：工作区标签、隐藏与置顶

- 状态：已采纳（0.1.2）
- 日期：2026-10-20

## 背景

DSH 侧栏的工作区区域只有一个区域级 slot（`sidebar.workspaces`），没有逐工作区的 slot，也没有可扩展的行内操作 API。本轮要加三件事：

1. 给每个工作区挂一个**标签**（灰色胶囊：灰底填充 + 彩色圆点 + 灰白文字，≤6 字），显示在侧栏工作区行右侧；
2. 把整个工作区（含其下会话）从侧栏**隐藏**，当前会话所在工作区除外；
3. 把工作区**置顶**，排到侧栏最前。

标签与隐藏是纯显示层需求；置顶会改变顺序，而顺序归宿主的工作区模型所有，不能靠画上去。

## 决策

### 标签：DOM 注入 + 注入 CSS

- 以 `[data-slot="sidebar.workspaces"]` 为根，按 `[data-row-key="workspace:<id>"]` 定位工作区行，把 `.dsh-lookout-ws-tag` 灰色胶囊徽标（灰底填充 + 彩色圆点 + 灰白文字）插入到工作区行内、操作按钮之前，靠右对齐。
- 徽标是工作区行（`div.projectRow`）的直接子节点，不再放进标题容器；`margin-left:auto` 把它推到行右端，行本身的 `gap` 提供与名字的最小间距。悬停出现「⋯」时，徽标在按钮左边，两者不重叠；名字仍从左开始、过长省略。
- 标签最多 6 个 Unicode 字符；颜色固定 8 种（red / orange / yellow / green / cyan / blue / purple / gray）。8 种颜色只作用于圆点，胶囊底色与文字继续用 `--dsw-alias-*` token，跟随宿主明暗主题。
- 徽标自身携带工作区 id，是幂等键：重复扫描只就地更新，不会叠加。
- MutationObserver + 200ms 去抖重扫；关闭开关或熔断时移除已注入的节点与样式。

### 隐藏：注入整组 CSS 规则

- 不搬动 DOM，而是为每个 hidden 工作区生成一条 CSS 规则（头部带锚点注释，每次重绘整份重新生成），把整组连同会话和「展开」按钮一起 `display: none`。
- 当前会话所在工作区永不隐藏；折叠组的 `folderActive`、官方 uiWorkspace 指向的工作区及其父工作区也纳入保护。
- 设置页表格取消勾选即删除规则、立即恢复；「清理失效项」按宿主当前工作区列表删掉已不存在的 id，避免偏好文件发霉。

### 置顶：走官方接口，不改宿主

- 通过 `ctx.inject(["workspaces"])` 拿到官方工作区服务，用 `insertBefore` 把置顶工作区移到最前。不写宿主代码，不改宿主的数据模型。
- 新建工作区默认插到最前，会挤掉置顶项；插件在列表变化后重放一次置顶顺序。
- 取消置顶时按 `pinAnchor`（置顶前紧邻位置的记录）还原，而不是简单追加到末尾。
- 只支持根工作区：子工作区的「置顶」勾选置灰——官方排序接口只作用于根级列表。

### 故障隔离

- 标签 / 隐藏连续 3 轮一个落点都找不到即熔断：断开观察、移除注入、只提示一次并提供「不再提示」；设置页仍有总开关。
- 置顶失败不影响标签 / 隐藏；DOM 注入失败也不影响置顶。

## 备选

1. **改 DSH 本体，新增逐工作区 slot 与行操作 API**：最干净，但插件无法自行发布，要等上游接受并随版本分发，而且会让插件依赖一个尚不存在的契约（同 ADR 0001 的结论）。
2. **自己重渲染整个侧栏工作区列表**：能拿到完全控制权，但要复刻展开 / 折叠、拖拽、键盘导航、选中态、滚动与刷新，任一处不同步就与宿主行为分叉，宿主升级时同样会坏。
3. **用 CSS `order` 实现置顶**：只能骗过眼睛，宿主内部顺序没变，键盘导航、拖拽落点、新建工作区的插入位置仍按旧顺序；刷新后还得靠脚本来回摆，故否决。
4. **置顶也用 DOM 搬节点**：与宿主的 React 对账冲突，下一次渲染就被搬回去，故否决。

## 后果

- 正面：零宿主改动即可交付；标签 / 隐藏最坏只是「功能不可见」，侧栏原生的展开、拖拽、选中行为保留；置顶走官方契约，宿主小版本升级相对稳。
- 负面：标签 / 隐藏依赖宿主 DOM 结构（`sidebar.workspaces`、`data-row-key`、行内的标题与操作按钮层级）。DSH 升级换结构时两者可能同时消失，已用「3 次熔断 + 一次性提示 + 总开关」把影响限制在功能不可见。
- 风险：置顶依赖官方 `workspaces` 服务与 `insertBefore` 的语义；宿主若改排序实现或改变「新建插到最前」的行为，重放会失效或错位。
- 风险：新建工作区默认插到最前，重放前会有一瞬的顺序跳动；只支持根工作区，子工作区不参与置顶。
- 风险：偏好文件在宿主侧，跨浏览器一致；RPC 失败时客户端用 localStorage 镜像兜底，此时改动只在当前浏览器生效，并提示一次「保存失败」。
- 可观测性：注入失败只 `console.warn` 一次；熔断提示可「不再提示」持久关闭。

## 数据落盘

- 文件：`$DSH_HOME/custom-favicon/workspace-prefs.json`（与图标、未读规则同目录）。
- 形状：`{ version: 1, workspaces: { [workspaceId]: { tag, color, pinned, hidden, pinAnchor } } }`。
- 归一化：标签去控制字符、trim、按 Unicode 码点截到 6 字；颜色白名单外回退 gray；id 只接受安全字符；未知字段丢弃；不带任何偏好的条目直接删掉。
- 读写：宿主侧 RPC 端点 `dsh-lookout#iconCustom/getWorkspacePrefs` / `dsh-lookout#iconCustom/setWorkspacePrefs`；设置表改动去抖 250ms 后整份提交。
- 客户端镜像：`localStorage["dsh-lookout.workspacePrefs"]`；启动拉取失败时用它，保存失败时改动也只落本机。

## 现状与验收

- 实现：设置页 `settings.section` order=56「工作区管理」；客户端逻辑在 `client/client.js` 的 workspace rows 区域；宿主偏好读写在 `lib/icon/workspace-prefs.js` 与 `lib/icon/index.js`，RPC 契约在 `lib/typert.host.js`。
- 离线验收：`test/workspace-rows.test.mjs` 覆盖标签注入与就地更新、隐藏规则与当前会话保护、熔断、RPC 失败降级、设置表提交；`test/workspace-prefs.test.mjs` 覆盖偏好文档归一化与落盘。
- 人工验收：设标签后侧栏工作区行右侧出现灰色胶囊——灰底填充、彩色圆点、灰白文字（名称仍左对齐、过长省略，悬停时徽标在「⋯」左边）；勾隐藏后整组消失，切到该组会话时恢复；置顶后刷新仍在最前，新建工作区后置顶项回到最前；取消置顶回到原位；子工作区的置顶勾选为灰；清掉浏览器数据后偏好仍在（来自宿主文件）。
